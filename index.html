Manuelle System-Bereinigung

Wähle dein Betriebssystem und kopiere die Befehle direkt in dein Terminal:

Windows (PowerShell Administrator)

# Temp-Dateien löschen Remove-Item -Path "$env:TEMP\*" -Recurse -Force -ErrorAction SilentlyContinue Remove-Item -Path "C:\Windows\Temp\*" -Recurse -Force -ErrorAction SilentlyContinue # Papierkorb leeren Clear-RecycleBin -Force -ErrorAction SilentlyContinue

macOS (Terminal)

# App- & Benutzer-Caches löschen rm -rf ~/Library/Caches/* # System-Logs leeren sudo rm -rf /private/var/log/* # DNS-Cache leeren sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder

Linux (Ubuntu/Debian Terminal)

# Paket-Cache & Restmüll entfernen sudo apt clean && sudo apt autoremove -y # Thumbnail-Cache löschen rm -rf ~/.cache/thumbnails/* # System-Logs bereinigen (max 50MB behalten) sudo journalctl --vacuum-size=50M
